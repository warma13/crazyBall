## 概述

竖屏弹珠台放置类游戏。玩家投放钢珠，钢珠撞击弹钉后落入底部口袋获得金币，金币用于升级球、口袋和各种自动化能力。

## 屏幕布局

| 区域 | 位置 | 内容 |
|------|------|------|
| 顶栏 | 顶部 60px | 金币数量、自动投放状态 |
| 弹珠台 | 上半屏 52% | 弹钉阵列、钢珠物理模拟、口袋 |
| 功能面板 | 下半屏 48% | 标签页 UI（钢珠/口袋/升级） |
| 投放按钮 | 面板与标签栏之间 | 圆形按钮，显示当前球颜色 |

## 核心循环

```
投放钢珠（消耗金币）
  → 钢珠撞击弹钉（触发球类特殊效果）
  → 落入口袋（口袋倍率 × 球价值 = 收益）
  → 获得金币
  → 升级球/口袋/自动化
```

## 轮次系统

### 基本规则

- 每轮 **60 秒**倒计时
- 每轮有一个**目标收益值**，在时间内达到则**无缝进入下一轮**（不暂停、不清弹珠）
- 未达到目标则失败，**金币和宝石清零**，2.5 秒后自动重试当前轮次

### 目标值增长

| 轮次 | 目标值 | 公式 |
|------|--------|------|
| 1 | 30 | 30 |
| 2 | 40 | 30 × 1.35 |
| 3 | 54 | 30 × 1.35² |
| 4 | 73 | 30 × 1.35³ |
| N | — | floor(30 × 1.35^(N-1)) |

### 配置参数

| 参数 | 值 | 说明 |
|------|-----|------|
| TIME_LIMIT | 60 | 每轮时间（秒） |
| BASE_TARGET | 30 | 第1轮目标值 |
| GROWTH_RATE | 1.35 | 目标值每轮增长倍率 |

> 注意: 没有通关奖金机制（已移除 COMPLETION_BONUS）。

### 顶栏 HUD

| 区域 | 内容 |
|------|------|
| 左侧 | 当前金币数 |
| 中央 | 第N轮 + 倒计时（>30s绿色，10-30s黄色，<10s红色脉冲） |
| 右侧 | 收益/目标 进度文字 |
| 底部 | 进度条（蓝→绿渐变填充） |

### 状态流转

```
Start() → StartRound(1)
  ↓
roundPhase = "playing"（游戏正常运行）
  ↓
├─ roundEarned >= roundTarget → OnRoundSuccess()
│    ↓ 飘字"过关!" + 下一轮目标提示
│    ↓ 无缝推进: round+1, 重置倒计时和roundEarned
│    ↓ roundPhase 保持 "playing"（不暂停）
│    ↓ 场上弹珠保留，继续运动
│
└─ roundTimeLeft <= 0 → OnRoundFailed()
     ↓ roundPhase = "failed"
     ↓ 飘字"时间到" + 完成度%
     ↓ 金币和宝石清零
     ↓ 2.5秒后自动重试 StartRound(N)
```

### 暂停机制

- `roundPhase != "playing"` 时，HandleUpdate 提前返回
- 物理、自动投放、天降弹珠全部暂停
- NanoVG 渲染仍继续（飘字可见）
- `roundTransitionTimer` 倒计时仍在更新（用于失败后自动重试）

### 平衡设计

- 第1轮目标仅 30，铁球手动投放即可轻松完成
- 1.35 倍增长率较平缓，匹配球类解锁和升级的指数增长节奏
- 失败惩罚严厉（清空金币和宝石），鼓励玩家在每轮内合理分配升级资源

## 代码架构

```
scripts/
├── main.lua        # 入口，生命周期，主循环
├── Config.lua      # 所有配置常量
├── State.lua       # 共享游戏状态（单例）
├── EventBus.lua    # 轻量发布/订阅事件总线
├── Physics.lua     # 物理模拟、投球、落袋结算
├── Renderer.lua    # NanoVG 渲染（弹珠台、球、钉、口袋、飘字）
├── Slots.lua       # 口袋管理（解锁、升级）
├── Upgrades.lua    # 升级逻辑（球、自动化、抽取）
├── GameUI.lua      # UI 面板（标签页、按钮、事件订阅）
├── SaveSystem.lua  # 存读档系统（云端读→本地缓存→同步写）
└── Leaderboard.lua # 排行榜模块（clientCloud 双字段存储）
```

### 模块间通信

采用 EventBus 发布/订阅模式，避免模块间直接回调耦合。

| 事件 | 发射方 | 响应 |
|------|--------|------|
| `tab_changed` | GameUI | 更新标签栏高亮 + 刷新内容 |
| `ball_changed` | Upgrades | 更新投放按钮颜色 + 刷新内容 |
| `slot_changed` | Slots | 刷新口袋页内容 |
| `slot_added` | Slots | 重算物理布局 + 重建钉子 + 刷新内容 |
| `upgrade_changed` | Upgrades | 刷新升级页内容 |
| `effect_drawn` | Upgrades | 刷新升级页内容 |
| `round_started` | main | 关闭结算弹窗 |
| `round_ended` | main | 显示结算弹窗（含 success/round/earned/target/bonus/nextTarget） |
| `round_continue` | GameUI | 开始下一轮 StartRound(N+1) |
| `round_retry` | GameUI | 重试当前轮 StartRound(N) |

唯一的直接引用: `GameUI.Physics = Physics`（投放按钮需调用投球函数）。
