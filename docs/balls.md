# 钢珠系统

> 更新时间: 2026-03-29 17:05:00  
> 版本: v1.1.0

---

## 概述

共 8 种球，铁球免费（初始已解锁，等级 1），其余初始等级 0（需花金币解锁）。每种非铁球拥有独特特殊效果。

球的实际产出价值 = `baseValue * level`，可通过升级无限提高。

## 效果实现细节

### 弹力 (bouncy) — 铜球

- 碰撞弹跳衰减从默认值提升至 0.78，球弹得更远撞更多钉
- 代码位置: `Physics.lua` 碰撞处理

### 分裂 (split) — 银球

- 球记录 `pegHits` 计数，达到 5 次后在碰撞点生成一颗同类型免费球
- 分裂球不会再次分裂（`pegHits` 不继续计数）
- 代码位置: `Physics.lua` → `UpdateBalls` 碰撞段

### 点金 (midas) — 金球

- 每次撞钉碰撞时直接 +1 金币到账户
- 代码位置: `Physics.lua` → 碰撞回调

### 暴击 (crit) — 钻石球

- 落袋时 15% 概率判定，触发时收益翻倍并显示"暴击!"飘字
- 可与抽取效果"暴击光环"叠加（暴击光环提供全局暴击概率）
- 代码位置: `Physics.lua` → `OnBallLanded`

### 灼烧 (blaze) — 红宝石球

- 每次撞钉碰撞时直接 +2 金币到账户
- 机制与点金相同，数值更高
- 代码位置: `Physics.lua` → 碰撞回调

### 聚财 (fortune) — 翡翠球

- 落袋时在倍率收益基础上额外加 `ball.value * bonusRatio` 的奖金
- `bonusRatio` = 0.2（即额外 20%）
- 可与抽取效果"翡翠强化"叠加（增加 bonusRatio）
- 代码位置: `Physics.lua` → `OnBallLanded`

### 冲击 (impact) — 陨石球

- 重力乘以 `gravityMult`(1.3)，球下落更快
- 落袋倍率乘以 `(1 + multBonus)`，即 ×1.3
- 代码位置: `Physics.lua` → 投放逻辑 + `OnBallLanded`

## 升级机制

### 解锁与升级流程

- 初始状态: `ballLevels = { 1, 0, 0, 0, 0, 0, 0, 0 }`（铁球已解锁 Lv.1，其余锁定）
- 等级 0 → 花费 `cost` 解锁至等级 1
- 等级 1+ → 继续升级，无上限

### 升级费用公式

```
GetBallUpgradeCost(index):
  if level == 0: return bt.cost        -- 解锁费用
  else: return floor(max(bt.cost, 10) * 1.5^(level-1))
```

> 注意: 增长倍率为 **1.5**（不是 1.8），低于口袋升级的 1.8。

### 价值计算

```
球的价值 = baseValue * level
```

在 `Physics.lua` 中投放球时计算 `value = ballType.baseValue * level`。

### 一键升级

`Upgrades.BulkUpgradeBall()` 可对当前选中球花光金币连续升级，与口袋的 `BulkUpgradeSlots()` 类似。

### 操作交互

点击球按钮的行为（`Upgrades.OnBallButtonClick`）：

| 当前状态 | 点击行为 |
|---------|---------|
| 未解锁 (level=0) | 花费 cost 解锁，自动切换为当前球 |
| 已解锁且是当前选中球 | 花费升级费用升一级 |
| 已解锁但非当前球 | 切换为当前选中球（不消耗金币） |

> 代码位置: `Upgrades.lua` → `OnBallButtonClick`
