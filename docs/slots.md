# 口袋系统

> 更新时间: 2026-03-29 16:05:12  
> 版本: v1.1.0

---

## 基本规则

- 初始 10 个口袋（`CONFIG.MAX_SLOTS = 10`），全部默认解锁
- 初始等级 2（对应倍率 x2）
- 所有口袋均为好坑，落袋收益 = `球价值 * 口袋倍率`

---

## 无限升级机制

口袋采用**无限升级**，不再有固定阶梯。

### 倍率公式

```
等级 N 对应倍率 = max(N, floor(1.3 ^ (N-1)))
```

| 等级 | 倍率 | 说明 |
|------|------|------|
| 1 | x1 | 最低 |
| 2 | x2 | 初始等级 |
| 3 | x3 | |
| 4 | x4 | |
| 5 | x5 | |
| 10 | x13 | |
| 15 | x51 | |
| 20 | x190 | |
| 30 | x2619 | |

### 升级费用公式

```
从等级 N 升到 N+1 的费用 = floor(60 * 1.8 ^ (N-1))
```

| 当前等级 | 升级费用 |
|---------|---------|
| 1 | 60 |
| 2 | 108 |
| 3 | 194 |
| 5 | 629 |
| 10 | 16,376 |
| 15 | 426,390 |
| 20 | 11,105,799 |

## 倍率颜色

采用**连续渐变**算法，支持任意倍率值，不再是固定映射。

- 倍率 <= 1: 灰蓝 `(100, 115, 140)`
- 倍率 > 1: 基于 `log2(mult)` 映射到色环，三相正弦函数生成 RGB
- 高倍率自动提升亮度（`bright = min(1.3, 1.0 + log2(mult) * 0.02)`）

---

## 一键升级

`BulkUpgradeSlots()` 支持一键升级所有口袋：
- 轮流对每个口袋执行升级，尽量保持各口袋等级均匀
- 直到金币不足以升级任何口袋为止
- 触发 `slot_changed` 和 `save_trigger` 事件
